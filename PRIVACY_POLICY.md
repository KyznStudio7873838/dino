# Kebijakan Privasi — Dino Runner (KyznStudio)

Terakhir diperbarui: [ISI TANGGAL]

Dino Runner ("Aplikasi") dikembangkan oleh Kyzen Team ("kami"). Kebijakan ini menjelaskan data apa yang dikumpulkan dan bagaimana data itu digunakan.

## 1. Data yang disimpan di perangkat
Sebagian besar progres permainan (skor tertinggi, koin, berlian, skin, pencapaian, pengaturan suara) disimpan secara lokal di perangkat kamu memakai `localStorage`. Data ini **tidak dikirim ke server manapun** kecuali kamu memilih login ke Akun Online.

## 2. Akun Online (opsional)
Jika kamu memilih membuat "Akun Online" untuk menyinkronkan progres antar perangkat, kami menyimpan:
- Username yang kamu pilih
- Password (disimpan dalam bentuk hash + salt menggunakan scrypt — bukan teks asli)
- Data progres permainan (skor, koin, berlian, item terbuka, pencapaian)

Akun Online bersifat opsional. Kamu bisa memainkan game sepenuhnya tanpa membuat akun.

## 3. Data yang TIDAK kami kumpulkan
Kami tidak mengumpulkan: nama asli, email, nomor telepon, lokasi, kontak, foto/media perangkat, riwayat browsing, atau data finansial.

## 4. Pembagian data ke pihak ketiga
Kami tidak menjual atau membagikan data pengguna ke pihak ketiga mana pun.

## 5. Keamanan
Password di-hash sebelum disimpan. Koneksi ke server akun menggunakan HTTPS. Token sesi kedaluwarsa otomatis setelah 30 hari.

## 6. Penghapusan data
Kamu bisa menghapus data profil kapan saja lewat menu "Hapus data profil ini" di dalam game, atau menghubungi kami di [ISI EMAIL KONTAK] untuk meminta penghapusan akun online.

## 7. Anak-anak
Aplikasi ini ditujukan untuk pengguna umum. Kami tidak sengaja mengumpulkan data pribadi dari anak di bawah umur di luar yang dijelaskan di atas (username buatan sendiri, tanpa data identitas nyata).
